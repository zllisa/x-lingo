Global Rules

全局产品规则

用户操作优先级

后台暂停 ＞ 取消/拖动/长按/多选 ＞ 回声录音 ＞ 重复模式 ＞ 正常播放自动跟随。

登录与本地模式

登录后进行云同步；游客不被阻断，数据保留于本地持久化状态。

错误可恢复

网络、AI、转写、录音和播放失败必须退出加载态，保留已有内容并提供重试。

性能

字幕虚拟列表与行级记忆化；词高亮只更新当前句，长任务离开页面后继续。
